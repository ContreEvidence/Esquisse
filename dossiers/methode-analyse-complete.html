Construire une analyse complète sans empiler les indicateurs

Le but n’est pas de produire le plus de données possible. Il est de hiérarchiser les informations, formuler un scénario, identifier ce qui peut le casser et décider si le rapport rendement/risque est suffisant.

← Espace avancéQuestionGrilleContradictionsDécision

1. Commencer par la question d’investissement

Une analyse n’a de sens que si elle répond à une question explicite : investissement long terme, swing de quelques semaines, arbitrage sectoriel, protection du portefeuille ou comparaison avec un indice de référence. L’horizon détermine le poids relatif des signaux.

2. La grille en cinq dimensions

DimensionQuestion principaleSortie attendue
MacroLe régime aide-t-il ou pénalise-t-il le scénario ?Vent porteur, neutre ou contraire
FondamentalL’entreprise crée-t-elle durablement de la valeur ?Qualité, trajectoire, risques structurels
ValorisationQue faut-il croire pour justifier le prix ?Marge de sécurité et rendement implicite
TechniqueLe marché confirme-t-il le scénario maintenant ?Niveaux, timing, invalidation
RisqueQuelle taille le portefeuille peut-il absorber ?Poids, perte plausible, corrélations

3. Les contradictions sont l’information la plus utile

Une entreprise peut être excellente mais trop chère ; un indice peut être techniquement haussier alors que le régime macro se dégrade ; une valorisation peut devenir attractive alors que la tendance reste baissière. Au lieu de masquer ces contradictions, il faut les faire apparaître.

ConvergencePlusieurs dimensions racontent la même histoire : la conviction peut augmenter.
DivergenceLes dimensions se contredisent : réduire la taille, attendre ou formuler une condition d’entrée.

4. Une conclusion doit être falsifiable

Une vraie conclusion comporte quatre éléments : scénario central, potentiel attendu, risque principal et condition d’invalidation. Sans invalidation explicite, une thèse peut être maintenue indéfiniment malgré les faits.

Format de conclusion : « Le scénario est favorable si A et B se produisent. Le prix offre X sous ces hypothèses. La thèse devient moins attractive si C apparaît. La taille maximale est limitée par D. »
