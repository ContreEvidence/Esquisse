Les taux de base : commencer par ce qui arrive habituellement

Un cas spectaculaire attire l’attention, mais une prévision fiable doit aussi tenir compte de la fréquence habituelle du phénomène.

Nous évaluons facilement une histoire particulière. Nous oublions plus facilement la proportion de cas semblables qui aboutissent réellement au résultat attendu.

Pourquoi j’en parle

Une histoire convaincante attire immédiatement mon attention. C’est justement le moment où j’essaie de revenir aux cas comparables. Une exception possible n’est pas encore une exception probable.

Le réflexe le plus courant

Un projet possède une équipe convaincante, une technologie impressionnante ou un récit exceptionnel. Ces éléments semblent suffire pour conclure qu’il réussira.

Ils peuvent compter, mais ils doivent être comparés à ce qui arrive généralement aux projets de la même catégorie.

Ce que je regarde autrement

Le taux de base correspond à la fréquence observée d’un événement dans un ensemble pertinent. Il fournit un point de départ avant l’analyse des particularités.

Ignorer ce point de départ conduit à surestimer les cas vivants, mémorables ou proches de nos attentes.

Choisir la bonne catégorie

Un taux de base trop large devient peu informatif. Un taux trop étroit repose sur trop peu de cas.

L’enjeu consiste à sélectionner une classe de référence suffisamment comparable : même secteur, même maturité, même contrainte ou même type de décision.

Combiner général et particulier

Le taux de base n’interdit pas l’exception. Il oblige à montrer pourquoi ce cas devrait s’écarter de la fréquence habituelle.

Les éléments particuliers doivent donc modifier progressivement l’estimation, pas remplacer toute l’information historique.

Le récit contre la fréquence

Une histoire cohérente donne l’impression d’une forte probabilité, même lorsqu’elle décrit un événement rare.

Plus le récit est séduisant, plus il est utile de demander combien de cas semblables ont réellement abouti.

Ce que vous pouvez tester

Avant une prévision, cherche la classe de référence. Demande ensuite quels faits spécifiques justifient une différence avec le taux habituel.

Commencer par l’extérieur — les cas comparables — protège contre l’enthousiasme excessif produit par le cas particulier.

Ce que j’en retiens

Je commence par ce qui arrive habituellement, puis je cherche les raisons précises pour lesquelles ce cas pourrait être différent.

Une histoire explique comment quelque chose pourrait arriver. Le taux de base rappelle à quelle fréquence cela arrive réellement.

Concepts liés

  • Penser en probabilités
  • Le biais du survivant
  • Le biais de confirmation
Ma règle de travail : partir du réel, distinguer les faits des hypothèses, chercher l’objection la plus solide, puis proposer une action que l’on peut réellement tester.
